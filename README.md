## Первый запуск

После скачивания откройте терминал в папке проекта.

```powershell
python -m pip install -r requirements.txt
python main.py
```

На новой установке автоматически создаются база и первый администратор.
Логин и случайный пароль появятся в терминале. Сохраните их и войдите на сайте.
При повторном запуске существующие аккаунты сохраняются.
Каждая отдельная установка получает собственные данные входа.

Для совместной работы с одной базой запускайте один сервер и открывайте его адрес с компьютеров команды.
